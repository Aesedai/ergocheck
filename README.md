# ErgoCheck

A small multi-tenant workplace ergonomic self-assessment app: employees complete a short assessment, get a risk score with guidance, and org admins see an aggregate view of their own organization only.

Built as a full-stack portfolio piece: React + TypeScript front end, a typed Fastify API, PostgreSQL with checked-in migrations, cookie sessions, role-based access, and tenant isolation enforced in the database.

> Work in progress. Architecture, setup and the live demo link will be added as features land.
